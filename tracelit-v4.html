What is masked language modeling and how does it differ from traditional language models?
TraceLit 10:23

Masked language modeling (MLM) is a pre-training technique where random tokens are masked in the input sequence, and the model learns to predict them based on bidirectional context¹. Unlike traditional left-to-right language models that only see previous tokens, MLM enables the model to simultaneously utilize both left and right context².

The key innovation is that 15% of tokens are randomly selected for masking, and the model must predict the original vocabulary id based solely on surrounding context¹. This approach was inspired by the classic Cloze task, allowing BERT to learn deeper bidirectional representations than any prior approach³.

How does the attention mechanism work in transformers?
TraceLit 10:25

The attention mechanism computes a weighted sum of values based on the compatibility between a query and a set of keys¹. Each head performs scaled dot-product attention: queries are dotted with keys, scaled by √d_k, then a softmax produces the attention weights applied to the values².

3. Pre-training BERT
3.1 Masked LM
BERT's pre-training uses two unsupervised tasks. The first is Masked Language Modeling (MLM), which we describe here.
We mask 15% of all input tokens at random and train the model to predict the original vocabulary id of the masked word based only on its context. Unlike traditional left-to-right language model pre-training, the MLM objective enables the representation to fuse the left and right context, which allows us to pretrain a deep bidirectional Transformer.
In contrast to denoising auto-encoders, we only predict the masked words rather than reconstructing the entire input. Although this allows us to obtain a bidirectional pre-trained model, a downside is that we are creating a mismatch between pre-training and fine-tuning, since the [MASK] token does not appear during fine-tuning.
3.2 MLM Inspiration
The MLM approach was inspired by the Cloze task (Taylor, 1953). While it is straightforward to train deep bidirectional models with MLM, we note that we cannot simply mask the input and train the model to predict masked tokens, as this would allow the model to trivially predict every token by looking at its mask token.
