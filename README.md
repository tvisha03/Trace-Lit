# TraceLit — Intelligent Academic Literature Assistant

> **Sentence-level attribution, confidence scoring, and hallucination prevention for multi-document research synthesis.**

TraceLit is a state-of-the-art literature review and research assistant designed for scholars and researchers. It bridges the gap between Large Language Models and academic rigor by enforcing strict, sentence-level grounding across multiple documents using the **HAVF (Hallucination-Aware Verification Framework)** pipeline.

---

## 🏛️ Project Vision

TraceLit aims to solve the "hallucination problem" in academic RAG (Retrieval-Augmented Generation) by:
1.  **Verified Grounding**: Every sentence generated by the assistant is verified against the source text.
2.  **Visual Evidence**: Instant access to tables, figures, and exact PDF locations for every claim.
3.  **Multi-Paper Intelligence**: Synthetic analysis across dozens of papers, from side-by-side comparisons to research gap discovery.
4.  **Local-First Privacy**: Your research data stays on your machine, with optional high-performance cloud inference via Gemini or Groq.

---

## 🏛️ Transformation Type Classification

TraceLit classifies how each generated claim relates to its source text to help researchers understand the reliability of each attributed claim:
- **Direct Quote**: Text closely matches source. Can be cited directly without modification.
- **Paraphrase**: Same meaning, different words. Requires verification of wording accuracy.
- **Synthesis**: Combines information from multiple papers. Must verify all contributing sources independently.
- **Inference**: Logical conclusion not directly stated in the source. Must be independently verified before citing.
- **Uncertain**: Ambiguous classification due to conflicting signals.
- **Unsupported**: No good retrieval match found (potential hallucination). Do not cite.

The UI displays color-coded badges and tooltips to instantly communicate these transformation types.

## 🔬 Research Publication & Evaluation

The transformation taxonomy and evaluation methodology implemented in TraceLit form the basis of a formal study on hallucination prevention in academic RAG systems.
- **Evaluation Results**: Our findings show Direct Quotes have 92% factual accuracy, while Inferences drop to 40%, validating that transformation type strongly predicts claim reliability.
- **Details**: Check `evaluation/README.md` for the full methodology and dataset.

## 🚀 Key Features

### 1. HAVF: Verified Science Engine
The core of TraceLit is the **Hallucination-Aware Verification Framework**. Unlike standard RAG, TraceLit runs a two-stage verification for every sentence:
*   **Level 1 (Semantic Match)**: Fast embedding-based similarity check.
*   **Level 2 (Cross-Encoder)**: Deep neural reranking to resolve nuances and ambiguous citations.
*   **Result**: Colour-coded confidence scores (High/Med/Low) for every claim in the chat.

### 2. Multi-Paper Analysis Studio
TraceLit doesn't just chat; it analyzes:
*   **Comparison View**: Structured side-by-side comparison of methodology, findings, and limitations using TanStack Table.
*   **Gap Finder**: Discovers research gaps by clustering topics across your entire library using DBSCAN.
*   **Literature Review**: Generates structured, cited reviews synthesizing multiple sources into a cohesive narrative.
*   **Automatic Summarization**: Extracts key contributions and abstracts as soon as a paper is uploaded.

### 3. Integrated Source Viewer
Click any citation in the chat to instantly:
*   **PDF Sync**: Jump to the exact page and paragraph in the original PDF.
*   **Visual Highlights**: See the verified sentence pulsed in the text.
*   **Visual Evidence**: View extracted tables and figures referenced in the text.

### 4. Smart Processing Queue
Upload up to 20 papers per session. The `SmartPaperQueue` manages:
*   **Parallel Extraction**: Layout-aware text and figure extraction.
*   **Memory Management**: Automatically pauses ingestion if system RAM exceeds 75%.
*   **Live Updates**: Track progress via WebSocket rings: `Extracting → Chunking → Embedding → Ready`.

## 📦 Getting Started

### Prerequisites
*   **Python**: 3.11 or higher
*   **Node.js**: 18.x or higher
*   **API Keys**: (Recommended) Gemini or Groq API keys for best performance.

### Installation

#### 1. Backend Setup
```bash
cd backend
python -m venv .venv
source .venv/bin/activate  # Or .venv\Scripts\activate on Windows
pip install -r requirements.txt
cp .env.example .env       # Configure your API keys here
python -m scripts.download_models
uvicorn app.main:app --reload --port 8000
```

#### 2. Frontend Setup
```bash
cd frontend
npm install
npm run dev
```
Visit `http://localhost:5173` to start your research session.
